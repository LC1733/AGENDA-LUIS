# Agenda Luis 5.0

Agenda personal con la estética de *Protocolo de Presencia*: rutinas semanales, eventos, medicamentos, recordatorios con sonido, dictado por voz, música de fondo, pausas de respiración guiada y sincronización entre teléfono y computador.

## Abrir la aplicación

https://lc1733.github.io/AGENDA-LUIS/

Los datos se guardan en el dispositivo y, si se conecta Google, en el espacio privado de la app dentro del Google Drive propio. Para recibir avisos con el teléfono bloqueado, usa **Ajustes → Pasar todo al calendario**.
